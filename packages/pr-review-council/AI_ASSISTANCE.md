# AI assistance disclosure

AI assistance was used to help draft the initial implementation, tests, examples, and documentation. Human-controlled acceptance criteria remained authoritative: deterministic offline behavior, bounded inputs, visible partial failures, exact evidence, safe rollback, and reproducible public fixtures.

Before publication, the project is checked through syntax validation, unit and transaction tests, a functional counter-proof, a disposable demo, wheel construction, and a secret-shaped-content scan. Maintainers remain responsible for reviewing changes and release decisions.
